# Architecture Diagrams

This folder contains multiple formats of the same package view for PANYPAN:

- `panypany-packages.wsd` (PlantUML, ASCII title)
- `panypany-packages.puml` (PlantUML, alternate extension)
- `panypany-packages.mmd` (Mermaid, subgraph-based package proxy)

Tips to preview in VS Code (Windows/PowerShell):
- Install a PlantUML extension. Most require Java or Docker; ensure one is available in PATH.
- If `.wsd` doesn’t preview, try opening the `.puml`—some extensions prefer it.
- For Mermaid preview, use an extension like “Markdown Preview Mermaid Support” and open the `.mmd` or embed in Markdown.

If preview still fails, tell me which extension you use and I’ll adapt the syntax or add a rendered image.
